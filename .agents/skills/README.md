# Skills

The skills in this directory are this repository's procedures. Start with
`overview`: it owns the file map and says which skill covers what.

Six come from Finpilot (overview, onboarding, customize, build, ci,
troubleshooting), each with an "Ampersand" section for what differs here.
`upstream-check` is Ampersand's own: check a tool's behaviour against its docs
and the real image before writing it into the spec or a PR.

Claude Code reads these through the `.claude/skills` symlink and `CLAUDE.md`.
